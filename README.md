# Salesforce Certified Marketing Cloud Next

Material de estudio base para adquirir conocimientos de Marketing Cloud y aprobar
el examen **Salesforce Certified Marketing Cloud Next**.

## Objetivo

Armar un cuerpo de material de estudio que sirva como base de conocimiento sobre
Marketing Cloud (línea "Next") y preparar la certificación con éxito.

## Contexto de partida

- Idioma del material: **español** (los términos técnicos de Salesforce se
  mantienen en inglés).
- Punto de partida: se conoce la plataforma core de Salesforce, pero **no**
  Marketing Cloud ni la línea "Next".
