# 3. La evolución de Marketing Cloud

Salesforce siempre ha sido líder en tecnología de marketing. Con Marketing Cloud
Next, hemos tomado todas las funcionalidades actuales de Marketing Cloud y las
hemos mejorado para guiar a los profesionales del marketing a través de la próxima
ola del marketing: el marketing de agentes.

Marketing Cloud Next es:

- **Más sencillo de usar**, con una interfaz de usuario moderna.
- **Totalmente unificado**, lo que proporciona a los profesionales del marketing un
  único conjunto de datos y un único flujo de trabajo.
- **Agentforce nativo**, con agentes de IA integrados desde el principio.

¿Y lo mejor de todo? Marketing Cloud Next funciona con tus productos y procesos de
Salesforce actuales. No se trata de reemplazar todo lo que ya tienes. Es una
continuación de Marketing Cloud que te facilita dar el siguiente paso hacia el
futuro del marketing de agentes.

# Marketing Cloud Next — Resumen

## Idea principal

Marketing Cloud Next busca resolver **3 grandes problemas del marketing tradicional**:

1. Datos difíciles de utilizar.
2. Experiencias multicanal difíciles de coordinar.
3. Demasiadas tareas manuales y herramientas desconectadas.

La propuesta de Marketing Cloud Next es combinar:

**Datos unificados + Experiencias multicanal + IA y Agentes + Automatización + Optimización**

---

## Comparación: Antes vs. Marketing Cloud Next

| Antes | Marketing Cloud Next |
|---|---|
| Datos dispersos y difíciles de consultar | Datos unificados y accionables |
| Dependencia de SQL, IT y Data Extensions | El marketer puede segmentar y analizar directamente |
| Campañas y journeys muy manuales | Automatización + agentes de IA |
| Canales y departamentos desconectados | Experiencias multicanal conectadas |
| Muchas herramientas diferentes | Plataforma integrada con Marketing, Ventas, Servicio y Commerce |
| Difícil medir resultados | Medición, atribución y optimización continua |

---

# 1. Comprender al cliente y el mercado

## Problema tradicional

Tener los datos del cliente no significaba necesariamente poder utilizarlos fácilmente.

Marketing muchas veces dependía de:

- SQL
- Data Extensions
- Equipos de IT
- Diferentes fuentes de datos
- Procesos manuales

Esto hacía más lenta la creación de segmentos, campañas y experiencias personalizadas.

## Con Marketing Cloud Next

Marketing Cloud Next permite trabajar con **datos unificados y accionables**.

Los marketers pueden utilizar esos datos para:

- Crear segmentos y audiencias.
- Comprender el comportamiento del cliente.
- Personalizar experiencias.
- Generar insights.
- Medir atribución.
- Analizar el rendimiento.
- Optimizar campañas.
- Alimentar agentes de IA.

### Concepto para recordar

**Datos → Insights → Segmentación → Personalización → Acción**

---

# 2. Gestionar experiencias multicanal

## Problema tradicional

Coordinar experiencias entre diferentes canales requería mucho trabajo manual.

Por ejemplo:

- Email
- Web
- Commerce
- Ventas
- Servicio
- Otros canales digitales

Además, cada departamento podía trabajar con plataformas y datos diferentes.

Esto generaba **silos de información** y experiencias desconectadas.

## Con Marketing Cloud Next

Marketing Cloud Next permite gestionar el **customer journey completo desde un mismo lugar**.

Los journeys pueden utilizar:

- Eventos y triggers.
- Personalización.
- Datos en tiempo real.
- Decisiones basadas en IA.
- División de journeys según comportamiento.
- Encadenamiento de journeys.
- Interacciones entre diferentes canales.

### Ejemplo conceptual

**Cliente realiza una acción**

↓

**Se genera un evento**

↓

**Marketing Cloud Next analiza los datos**

↓

**IA / reglas deciden qué hacer**

↓

**Se personaliza la experiencia**

↓

**El cliente continúa por el journey más adecuado**

### Concepto para recordar

**Orquestar todo el ciclo de vida del cliente entre canales y departamentos.**

---

# 3. Incrementar eficiencia y escalabilidad

## Problema tradicional

Marketing normalmente necesita combinar diferentes herramientas para:

- Segmentación.
- Contenido.
- Campañas.
- Journeys.
- Analytics.
- Ventas.
- Commerce.

Esto genera:

- Trabajo manual.
- Datos fragmentados.
- Procesos lentos.
- Experiencias desconectadas.
- Dificultad para demostrar ROI.

## Con Marketing Cloud Next

Marketing Cloud Next incorpora **agentes de IA integrados en la plataforma**.

Estos agentes pueden ayudar en diferentes áreas.

### Marketing

Pueden colaborar en:

- Creación de segmentos.
- Generación de contenido.
- Creación de promociones.
- Informes.
- Optimización de campañas.

### Ventas

Pueden ayudar a:

- Captar leads.
- Nutrir leads.
- Calificar leads.
- Identificar oportunidades.
- Derivar oportunidades a un SDR o vendedor.

### Customer Experience

Los agentes pueden interactuar con clientes **24/7** para:

- Responder preguntas.
- Recomendar productos.
- Ayudar con compras.
- Ayudar con reservas o programación.
- Personalizar experiencias web.

### Optimización y ROI

La IA puede analizar continuamente las campañas y detectar qué está funcionando.

Por ejemplo:

- Identificar anuncios con bajo rendimiento.
- Recomendar pausarlos.
- Optimizar campañas activas.
- Cambiar el recorrido del cliente según su comportamiento.
- Buscar que cada cliente siga el journey más adecuado.

Algunas acciones pueden requerir **aprobación humana**, manteniendo mecanismos de control y gobernanza.

Utilizar agentes de IA para ejecutar tareas, tomar decisiones y mejorar campañas.

---

# Diferencia conceptual importante

Marketing Cloud Next no debe entenderse simplemente como:

**"Marketing Cloud tradicional + IA"**

La idea es que:

**Datos + Workflows + IA + Agentes**

estén integrados dentro de una misma plataforma.

De esta manera, la IA no solamente genera contenido, sino que también puede:

**Analizar → Recomendar → Decidir → Ejecutar → Optimizar**

siempre dentro de los controles y reglas definidos por la organización.
